Comment ça marche

1. L'université enregistre

À la délivrance, l'empreinte du PDF est inscrite sur la blockchain par le compte officiel de l'université.

2. Vous déposez le PDF

Votre navigateur calcule l'empreinte du fichier. Une seule virgule modifiée donne une empreinte totalement différente.

3. Le contrat compare

L'empreinte est cherchée dans le registre : authentique, révoqué ou introuvable.

Les trois résultats possibles

AuthentiqueEnregistré et non révoqué.
RévoquéEnregistré mais annulé par l'université.
IntrouvableCette empreinte n'existe pas dans le registre.
