Comment ça marche

1. L'université enregistre

À la délivrance, l'empreinte du PDF est inscrite sur la blockchain par le compte officiel de l'université.

2. Vous déposez le PDF

Votre navigateur calcule l'empreinte du fichier. Une seule virgule modifiée donne une empreinte totalement différente.

3. Le contrat compare

L'empreinte est cherchée dans le registre : authentique, révoqué ou introuvable.

Les trois résultats possibles

AuthentiqueEnregistré et non révoqué.
RévoquéEnregistré mais annulé par l'université.
IntrouvableAucune trace dans le registre.

Questions fréquentes

Mon PDF est-il envoyé quelque part ?

Non. Seule l'empreinte (64 caractères) est utilisée pour interroger la blockchain. Le fichier reste sur votre ordinateur.

Pourquoi « introuvable » alors que le diplôme est vrai ?

Le PDF a peut-être été modifié, recompressé ou réexporté. Il faut déposer le fichier original délivré par l'université.

Dois-je payer ou utiliser un portefeuille ?

Non. La vérification est une simple lecture : gratuite et sans MetaMask.
